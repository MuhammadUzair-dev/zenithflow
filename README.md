# ZenithFlow 🌊 | Agentic AI Learning Architect

ZenithFlow is an autonomous, agent-driven web application that generates highly personalized 4-week learning roadmaps. It solves the problem of "tutorial hell" and information overload by acting as a personal skill architect.

## 🚀 Features (The Agentic Workflow)
*   **The Architect Agent:** Analyzes user goals and constructs a structured, day-by-day learning curriculum.
*   **Resource Scavenger:** Automatically sources high-quality, up-to-date learning materials (docs, videos, articles) for each topic.
*   **Progress Auditor:** Tracks user milestones and dynamically adjusts the roadmap based on completion rates.
*   **Sleek UI/UX:** Built with a modern, glassmorphism-inspired interface for a premium user experience.

## 🛠️ Tech Stack
*   **Frontend:** Next.js / React (or Vite, adjust as needed)
*   **Backend:** Node.js, Express
*   **Database:** PostgreSQL
*   **AI Integration:** Groq API (Llama 4 Scout) for high-speed, low-latency agentic reasoning.
*   **Deployment:** Vercel

## 📦 Quick Start for Buyers
1. Clone the repository: `git clone https://github.com/MuhammadUzair-dev/zenithflow.git`
2. Install dependencies: `npm install`
3. Rename `.env.example` to `.env` and add your keys (Groq API, Database URI).
4. Run the development server: `npm run dev`
